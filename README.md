# Hospital Readmission Prediction Using ANN

## About
A machine learning project that uses an Artificial Neural Network (ANN) to predict the likelihood of hospital readmission based on patient data.

## Technologies Used
- Python
- TensorFlow / Keras
- Pandas, NumPy
- Scikit-learn
- Streamlit
- Jupyter Notebook

## Features
- Patient data preprocessing and feature scaling
- ANN-based prediction
- Interactive web interface using Streamlit
